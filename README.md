## `FEATURED_BUILDS`

### 🔎 [Derived-Field Check](https://github.com/Amruthareddygurugari20/Derived-Field-Check)
Pre-registered study of silent arithmetic errors in LLM output (~750 generations). Numbers are fine when **stated**, wrong **20.8%** of the time when the model must count, **79.2%** when it must add. A reference-free checker recomputes derived fields from the model's own output and **catches 80.4%** of silent failures — **0 of 148 false alarms**, out of sample.
`Python · Ollama · pre-registered · submitted to Handshake AI Showcase`

### 🧭 [AI Client Discovery](https://github.com/Amruthareddygurugari20/Ai-client-discovery)
A **5-agent LangGraph** system that profiles any company in under 2 minutes, streaming per-node progress. Every fact carries a source URL and a **verified/inferred tag enforced by deterministic guardrails, not the model** — so unsupported claims are dropped.
`LangGraph · GPT-4o · Tavily · FastAPI · TypeScript`

### 🧪 [Reproducibility Watchdog](https://github.com/Amruthareddygurugari20/agent-watchdog)
Takes a biology paper + its repo; an LLM extracts dependencies, a **no-LLM rules layer** verifies version pins/registries, a human signs off, and it emits a pinned Dockerfile. Its two-check rule means a real citation **can't launder an invented claim**. Audited on 3 lab repos; caught 6 mislabels, each now a regression test.
`Python · Typer · Pydantic · Ollama (offline)`

### 🤖 [MiniClaude](https://github.com/Amruthareddygurugari20/minimal-coding-agent)
A coding agent built **from scratch, no framework** — a raw tool-use loop with 6 tools, a path jail, and a stdlib **AST code index** with deterministic ranking. Unique-match-or-refuse edits with a syntax gate + rollback. **55 tests**; a 300-task SWE-bench retrieval eval with a sealed hold-out.
`Python · no framework · local models · 55 tests`

### 🛰️ [OSINT Intelligence Dashboard](https://github.com/Amruthareddygurugari20/-Live-flights-)
A live map of breaking news events and **200+ aircraft** from real-time ADS-B feeds, with a **Claude analyst layer** that summarizes the whole map into a short brief.
`FastAPI · Leaflet.js · Claude API · ADS-B`

### 🥗 [FitSmart AI](https://github.com/Amruthareddygurugari20/FitsmartAi)
A **GPT-4 Vision** food scanner estimates a meal from a photo; **5 LangGraph agents** — each owning a domain (nutrition, workouts, progress) — share state through the graph behind a FastAPI backend.
`LangGraph · GPT-4 Vision · FastAPI`
